Image Metadata Viewer & Remover

Shows what hidden data your JPG, PNG and WebP images carry, such as camera model, date and GPS location. Removing it keeps the picture itself byte for byte unchanged.

    Keeps only the orientation tag so sideways photos still display upright.

    Kept by default so colors stay accurate.

    The image itself isn't re-encoded.

    Details & limits

    Metadata, including GPS location, is read and removed in your browser and the pixels aren't changed. For smaller files, use Image Size Reducer, which also removes metadata but re-encodes the image.
